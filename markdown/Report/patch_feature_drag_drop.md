# Drag-and-Drop 파일 공유 기능 추가

## 개요
채팅창 영역에 파일을 드래그하여 다른 참여자들과 쉽게 공유할 수 있는 기능을 추가했습니다.
PeerJS의 DataConnection을 통해 파일을 작게 나누어 전송하며, 대용량 파일 전송 시 안정성을 위해 청크(Chunk) 단위 전송 방식을 사용합니다.

## 변경 사항

### 1. UI 업데이트 (`index.html`)
- 채팅 영역(`.chat-section`)에 드래그 앤 드롭 이벤트를 시각적으로 보여주기 위한 오버레이(`drop-zone-overlay`)를 추가했습니다.
- 파일을 드래그하면 채팅창 위에 점선 테두리와 안내 메시지가 나타나도록 CSS 스타일을 적용했습니다.

### 2. 로직 업데이트 (`screenShare.js`)
- **드래그 앤 드롭 이벤트 핸들링**: 
  - `dragover`, `dragleave`, `drop` 이벤트를 감지하여 UI를 토글하고 파일을 처리합니다.
- **파일 전송 로직 (`sendFile`)**:
  - 파일을 16KB 단위의 청크로 분할하여 전송합니다.
  - 전송 단계: `file-start` (메타데이터) -> `file-chunk` (데이터) -> `file-end` (완료 신호).
  - 호스트는 모든 참여자에게 데이터를 브로드캐스트하고, 참여자는 호스트에게 데이터를 전송합니다 (참여자가 보낸 경우 호스트가 다시 브로드캐스트).
- **파일 수신 로직 (`handleFileStart`, `handleFileChunk`, `handleFileEnd`)**:
  - 수신된 청크를 메모리에 버퍼링합니다.
  - 전송이 완료되면 `Blob`을 생성하고 다운로드 링크를 채팅창에 표시합니다.

## 사용 방법
1. 채팅창 영역에 파일을 드래그 앤 드롭합니다.
2. 파일 전송이 시작되면 시스템 메시지로 알림이 뜹니다.
3. 전송이 완료되면 모든 사용자에게 다운로드 링크가 포함된 메시지가 표시됩니다.

## 주의 사항
- 현재 메모리 내에서 파일을 조립하므로, 브라우저 메모리 한계를 초과하는 초대용량 파일 전송은 권장하지 않습니다.
- P2P 네트워크 상태에 따라 전송 속도가 달라질 수 있습니다.
