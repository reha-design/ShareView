# 프로젝트 현황 보고서: 화면 공유 (P2P)

**작성일**: 2026-01-16
**상태**: 안정화 / 기능 검증 완료

## 1. 프로젝트 개요
본 프로젝트는 **PeerJS** (WebRTC 래퍼)를 활용한 웹 기반 **P2P 화면 공유** 애플리케이션을 구현합니다. 사용자는 구글 맵 인터페이스 위에서 중계 서버 없이 직접 다른 피어(Peer)와 화면을 공유할 수 있습니다.

## 2. 주요 기능
*   **호스트 (공유자)**:
    *   연결 시 고유 Peer ID 생성.
    *   `getDisplayMedia`를 통해 화면/창/탭 캡처.
    *   전송되는 스트림을 로컬에서 미리보기 (음소거).
    *   들어오는 연결 요청에 대해 현재 공유 중인 화면으로 자동 응답.
*   **뷰어 (시청자)**:
    *   호스트의 Peer ID를 사용하여 연결 시도.
    *   **수정 사항 적용**: 단방향 수신을 위해 '더미 스트림(Dummy Stream)'을 생성하여 연결 요청(PeerJS 요구사항 충족).
    *   원격 비디오 스트림을 수신하여 오디오와 함께 자동 재생.
    *   연결 성공 시 자동으로 전체화면 모드 전환 지원.
*   **UI/UX**:
    *   구글 맵을 베이스 레이어로 사용.
    *   P2P 연결 관리를 위한 플로팅 제어 패널.
    *   화면 시청을 위한 플로팅 비디오 컨테이너.

## 3. 최근 이슈 및 해결 내역
| 이슈 | 원인 | 해결 방법 |
|-------|-------|------------|
| `TypeError: Cannot read properties of undefined (reading 'on')` | `peer.call(id, null)` 호출 시 미디어 스트림 없이 연결을 시도하여, PeerJS가 정상적인 호출 객체를 생성하지 못함. | 1x1 픽셀 크기의 캔버스(Canvas)로 '더미 스트림(Dummy Stream)'을 생성하여, 연결 요청 시 함께 전달함으로써 해결. |

## 4. 파일 구조
*   **`index.html`**:
    *   메인 진입점.
    *   구글 맵 API 및 PeerJS CDN 로드.
    *   지도, 제어 패널, 비디오 컨테이너의 HTML 구조 정의.
*   **`screenShare.js`**:
    *   PeerJS 초기화 로직 (`new Peer()`).
    *   이벤트 핸들링: `open` (ID 생성), `call` (호스트 응답), `stream` (뷰어 수신).
    *   화면 캡처 로직 (`startScreenShare`).
    *   연결 로직 (`connectToPeer` - 더미 스트림 수정 적용).
    *   유틸리티: 전체화면 토글 기능.

## 5. 향후 개선 사항 / 보류 작업
*   **연결 안정성**: 네트워크 불안정 시 재연결 로직 추가.
*   **UI 개선**: "연결 중..." 상태에 대한 시각적 피드백 강화.
*   **모바일 지원**: 모바일 브라우저에서의 `getDisplayMedia` 호환성 검토 및 최적화.
