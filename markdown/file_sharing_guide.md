# 파일 공유 기능 사용 가이드

## 1. 파일 전송하기 (보내는 사람)
1. 공유하고 싶은 파일을 **마우스로 클릭하여 집습니다 (Drag)**.
2. 화면 왼쪽 하단의 **채팅창(`Chat`) 영역**으로 파일을 가져갑니다.
3. 채팅창 위에 점선 테두리와 함께 **"Drop files to share"** 문구가 나타나면 마우스 버튼을 놓습니다 (**Drop**).
4. **"Sending file..."** 메시지와 함께 전송이 시작됩니다.

## 2. 파일 다운로드하기 (받는 사람)
1. 상대방이 파일을 보내면 채팅창에 다운로드 링크가 표시됩니다.
2. **`💾 Download [파일명]`** 링크를 클릭합니다.
3. 브라우저의 다운로드 경로에 파일이 저장됩니다.

## 3. 주의 사항
*   **보안 컨텍스트**: 반드시 `https://` 주소(예: `https://localhost:3000`)로 접속해야 합니다.
*   **파일 크기**: 대용량 파일은 전송 시간이 오래 걸릴 수 있으며, 브라우저 메모리 상황에 따라 실패할 수 있습니다.
*   **연결 유지**: 전송 중에는 호스트 및 상대방과의 연결이 유지되어야 합니다.
